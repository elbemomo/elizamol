# Kit de Anuncios Modulares

**Grabas una vez y salen decenas de anuncios.** Un kit de Elizamol (Elizabeth Molina) que funciona con Claude Code.

Escribes un guion en bloques que se pueden combinar entre sí: ganchos, cuerpos y cierres. Lo grabas de una vez con el celular y Claude hace el resto en tu computador: encuentra cada bloque en el video, se queda con la última toma, lo corta y arma las combinaciones con título, subtítulos y música, listas para Meta en 9:16 y 4:5.

## Qué necesitas

- Un computador con Windows o Mac.
- La app de Claude con plan Pro o Max, para usar Claude Code.
- Unos 20 minutos la primera vez (casi todo es contarle de tu negocio).
- Tu celular para grabar.

## Instalación

1. **Descarga la app de Claude** desde [claude.com/download](https://claude.com/download), inicia sesión y entra a la pestaña **Code**.
2. **Descomprime este kit** en tu carpeta de usuario o en Documentos.
3. **Abre esa carpeta en Claude Code** y pega este mensaje:

```text
Quiero usar el "Kit de Anuncios Modulares" que está en esta carpeta. No sé nada
técnico: hazlo todo tú, no me pidas correr comandos ni tocar archivos, y explícame
cada paso en palabras simples. Lee primero el CLAUDE.md de la carpeta.

1) Prepara mi computador con scripts/instalar.py --arreglar hasta que diga LISTO.
2) Hazme la entrevista sobre mi negocio, una pregunta a la vez.
3) Escríbeme el guion (10 ganchos, 10 cuerpos y 3 cierres), muéstramelo en una
   tabla y déjame el teleprompter listo cuando lo apruebe.
4) Cuando te pase la grabación, córtala, arma 3 anuncios de prueba y, con mi OK,
   arma el resto con los textos para Meta.
```

> Si el computador pide permiso para instalar algo, acepta. Todo queda dentro de la carpeta del kit: para desinstalarlo, basta con borrarla.

## Después: solo pídeselo

| Le dices a Claude | Qué pasa |
|---|---|
| "hazme un guion nuevo" | Ganchos, cuerpos y cierres nuevos a partir de tu perfil |
| "dame el teleprompter" | El guion en orden para leer en cámara |
| "corta mi grabación" | Encuentra cada bloque y te cuenta qué faltó |
| "arma 30 anuncios" | Videos en `3_anuncios`, en 9:16 y 4:5 |
| "escríbeme los textos para Meta" | Texto principal y titular por cada ángulo |

## Qué hay adentro

| Carpeta | Para qué |
|---|---|
| `CLAUDE.md` | Las instrucciones que sigue Claude |
| `plantillas/` | El perfil del negocio y un guion de ejemplo inventado |
| `scripts/` | El motor: instalar, transcribir, cortar, combinar y armar |
| `negocio/` | Lo tuyo: perfil, guion, teleprompter y música |
| `1_grabaciones/` | Tu video crudo |
| `2_piezas/` | Los bloques cortados y el reporte |
| `3_anuncios/` | Los anuncios terminados |

Todo pasa en tu computador, incluida la transcripción, y no se paga nada aparte. Los anuncios que hagas son tuyos.
